# FF2 Analyzer

A static TF2 / Freak Fortress 2 analyzer designed for GitHub Pages.

## Features in this starter
- Browser-side VDF/KeyValues `.cfg` parsing
- Weapon database
- FF2 boss database
- Map database
- Searchable weapons, bosses & maps
- No backend required for the analyzer
